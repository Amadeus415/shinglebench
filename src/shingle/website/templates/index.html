What one run produces

A run gives one model, one brief and one random seed a sandbox with no internet, plus simulated ad, payment and supplier services. Nothing real is bought, sent or advertised. At the end we freeze everything it made.

How a business gets graded

Automated checks

A browser crawls the frozen site. It completes test checkout, submits forms, audits mobile layout and accessibility, and runs a QA agent against the brief's acceptance criteria. It also flags fake reviews, invented credentials and attempts to manipulate graders.

Blind human graders

Graders never see which model built a business. They score nine rubric dimensions with written anchors and compare businesses for the same brief side by side, with sides randomized. Gold items and attention checks keep the grading honest.

LLM judges, checked against humans

Judges use the same rubric. Every pairwise comparison runs twice with positions swapped, and we publish judge–human agreement for each dimension, so you can see where judges can be trusted.

Simulated customers produce weekly results so the model has something to iterate on. That market is a secondary signal and is never part of the score. Read the methodology.
